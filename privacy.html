RoleReady Privacy

Last updated September 13, 2026

RoleReady is an evidence-first job companion. It does not submit applications, scrape LinkedIn profiles, sell personal data, or train public models on a user’s private materials.

What the Chrome extension reads

On a supported job page, the extension reads the job-posting text and structured JobPosting data that is already visible in the page. It uses that context to build a Proof Map. The extension does not read unrelated browsing pages.

What is stored

  • Role and pipeline details a signed-in user chooses to save.
  • User-approved evidence such as projects and experience. Resume and LinkedIn-export imports are suggestions until approved.
  • Optional Proof Sprint, milestone, application-kit, assessment-result summary, and interview-scorecard data.

Raw assessment code is sent only to the execution provider and is not stored by RoleReady. Microphone audio is used only for the active transcription request and is not stored by default. A transcript or scorecard is saved only if the user opts in.

Connected services

RoleReady uses Supabase for authentication and private per-user records. When a user requests AI analysis, relevant approved evidence and selected job context may be sent to OpenRouter. Public company-resource searches may use Exa. Coding practice may send submitted code to Piston for execution. Optional deadline emails use Resend.

Control and deletion

Users control what becomes confirmed evidence and may delete their saved data from their RoleReady workspace. To request account-data help, open an issue in the RoleReady GitHub repository.

Contact

RoleReady is an open-source AI Tinkerers project. Questions can be submitted through the project repository.
